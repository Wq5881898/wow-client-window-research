## 1. 项目目标

用户的研究目标是评估 World of Warcraft: Forever 中个人账号自动化的技术可行性。固定区域、固定目标、全程旁观是当前讨论过的最小场景，不代表最终产品范围。

用户已经明确：

- 个人账号技术实验不等待 15C，并自行承担账号处罚风险。
- 直接自动化技术验证是主要研究方向。
- 玩家主导产品 B 和 W1 访谈不构成技术主线，也不作为技术路线失败后的必然替代。
- 产品形态与技术架构是两个独立维度。
- 高风险技术可以作为非操作性预研对象，不因风险标签永久排除其研究价值。

以上是用户决定的记录，不是 Blizzard 授权、法律意见或技术可行性证明。

## 4. 证据类型

项目中的结论按来源区分：

1. **文档化表面**：归档资料明确列出的 API、参数、标记、条款文字或历史事实。
2. **高置信推断或工作假设**：由多个静态事实支持、可用于设计实验，但尚未在目标客户端确认。
3. **运行时观察**：目标 build、具体场景和具体仪器产生的记录。
4. **合成结果**：仿真模型内的输出，只描述该模型和代码实现。
5. **用户决定**：用户对目标、优先级和风险承担的明确选择。

API 存在、仿真输出、历史材料、运行时观察和授权判断互不替代。
