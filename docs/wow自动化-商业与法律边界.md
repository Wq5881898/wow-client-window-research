## 二、MDY 案材料

`MDY Industries, LLC v. Blizzard Entertainment, Inc.`, 629 F.3d 928 (9th Cir. 2010)，含 2011-02-17 修正令。

项目归档记录的程序结果：

- 地区法院阶段涉及版权、合同干扰和 DMCA 等争议，并有 600 万及 650 万美元相关判决记录。
- 第九巡回撤销部分地区法院结论，维持 MDY 对 §1201(a)(2) 的责任，并保留相关永久禁令。
- 判决在该案事实下认为，违反 bot 禁令没有自动构成版权侵权，因为相关合同条款与版权专有权之间缺少所需 nexus。
- 案件事实包含 Glider 检测规避和商业销售。

这些事实可作为反检测、反规避和商业化风险的历史先验。它们没有确定本项目在其他事实、法域或当前合同下的结果，也没有证明个人使用的唯一后果是封号。

## 三、历史反作弊材料

MDY 判决描述了当时 Warden 的连接检查和周期性检查。2016 Anti-Cheating Agreement 列出了 RAM、游戏进程及附加代码、Windows process list 和 Windows handles list 等观察面。

这证明 Blizzard 曾公开描述这些历史观察面。它没有证明 Forever 当前实现相同、只有这些观察面，或截图、系统输入、硬件输入、零句柄方案不可检测或已获授权。

高风险技术在项目中的当前状态是：可以作为非操作性预研候选讨论依赖、成本和风险；尚无用户决定要求在当前环境实施。

## 四、竞品材料

Zygor 公开资料显示：

这些资料支持“此类公开产品形态和历史市场存在”。竞品自述、存续和免责声明不等于 Blizzard 对本项目授权，也不证明 Forever 当前需求、市场空白或零风险。

| 维度 | 已有事实 |

产品 B 的需求结果不会自动决定视觉架构 C；视觉或 API 架构也不会自动决定产品形态。
