# 北郡同次运行短步往返

## 过程

在同一次 Probehuman 客户端运行中依次采集 baseline、前进 0.15 秒、后退 0.15 秒和 final 四个快照。快照之间不执行 reload，最终样本后才统一落盘。角色保持 1 级人类法师、Northshire Valley、非战斗、无目标。

## 结果

相对 baseline 的归一化地图坐标变化：

| 阶段 | Δx | Δy | Δfacing |
| --- | ---: | ---: | ---: |
| baseline | 0 | 0 | 0 |
| forward | 0 | -0.00045356154441839047 | 0 |
| back | 0 | -0.00016203522682189941 | 0 |
| final | 0 | -0.00016203522682189941 | 0 |

前进产生了明确的负 y 位移；后退产生反向位移，但本次后退未完全抵消前进，返回残差为 `dy=-0.00016203522682189941`。最终静止样本与后退样本一致，说明采样结束后没有继续漂移。

## 解释边界

这组结果证明短步输入能改变位置，也证明同次运行内可以连续采集和落盘；不能把 0.15 秒前进与 0.15 秒后退假定为严格等距。

后续源码核验修正：本机 `Unit.cpp:92-96` 的玩家前进基础速度为 7.0，后退为 4.5。理论位移比 4.5/7=0.642857，实测后退/前进位移比 0.642749，相对偏差仅约 0.0168%。按该速度比预测的残差为 -0.0001619863，与实测残差相差约 -4.90e-08（归一化地图 y）。因此速度不对称已几乎完全解释此次残差，之前优先列举输入时序和释放余量的归因不充分。剩余微小偏差尚不能归因；源码默认速度也不等同于移动过程实时速度测量。

等距时长的理论对照为前进 0.15 秒、后退约 0.233333 秒；2026-10-28 已补做实测，残差减少 99.7425%，见 docs/37。汇总脚本已增加时间递增、位置有效、往返方向相反和最终无漂移校验，并将速度比分析写入结果 JSON。
