## 实机标定出的约定

| 项目 | 值 |
| --- | --- |
| 地图 x / y | 向东为正 / 向南为正 |
| 朝向 θ | 自北逆时针为正（`GetPlayerFacing()`） |
| 行走位移 | `u(θ) = (-sin θ, -cos θ)` |
| LEFT / RIGHT | θ 增大 / θ 减小 |
| 转向速率 | π rad/s |

朝向尸体：`θ_target = atan2(pos_x - corpse_x, pos_y - corpse_y)`。

## 排障记录（三类真问题）

1. **客户端起不来**。弹窗 `Running World of Warcraft through a Remote Desktop
   connection is not supported.`。原因是交互会话 1 变成了 `rdp-tcp#1`（挂着 RDP 标记），
   3.3.5a 直接拒绝启动。`tscon 1 /dest:console` 把会话转回控制台会话后正常启动。
   先前曾把"客户端起不来"往硬件方向查，方向是错的。
2. **点击全部点偏**。脚本里的坐标是 1920×1080 **游戏图坐标**，
   而客户端窗口当时在 `(72,1)` 且尺寸 1760×1029。新增 `client_geometry.py`
   做换算，并把 Enter World / Accept 两个按钮改成**画面检测**。
3. **走路按键时灵时不灵**。并发跑的诊断脚本调用 `hide_consoles()`，
   隐藏控制台窗口会**抢走前台焦点**，游戏就收不到按键。
   结论：驱动任务运行期间不得并发跑任何会隐藏窗口的脚本。

另有一个把人带偏的假象：探针的朝向值编码在 16 位里，**2π 会回绕**，
`0.5434 - π = -2.598` 回绕后是 `+3.685`，第一轮因此误判转向方向。所有角度
比较必须先过 `wrap()`。
