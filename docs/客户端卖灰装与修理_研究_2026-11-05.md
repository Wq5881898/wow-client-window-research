# 卖灰装与修理装备：这条路径的研究（2026-11-05）

目标：找到能**卖灰色垃圾物品**和**修理装备**的地方，并研究客户端路线能不能走通。

## 为了这条路径新增的能力

| 协议 | 字节 | 新增 | 为什么需要 |
| --- | --- | --- | --- |
| v12 | 140 | `money`（4 字节）、`bag_items`（1 字节） | 一笔交易必须能被核对：钱变了、袋子里的东西少了 |
| v13 | 140 | `cursor_name_hash`（2 字节） | 找到商人：光标下的单位叫什么名字 |

两个名字哈希都用同一个 djb2 变体（Lua 与 Python 各算一遍）：
`name_hash("Riding White Stallion") = 33001`、
`name_hash("Deputy Willem") = 43914`、`name_hash("Repair") = 51272`。

新增脚本：`scripts/lab_client_vendor_scan.py`（把光标扫过画面并记录看见的名字）、
`scripts/lab_client_cursor_probe.py`（在指定的几个点读名字）。

## 实测结论

1. **修理这条路现在被"没钱"卡住**：Probehuman 身上 **0 铜**
   （面板文本 `money=0`）。修理要花钱 → 必须先卖东西 → 卖东西也要先有商人。
2. **背包里只有 1 件东西**（`bags=1`）。也就是说这条路径的第一笔收入只有一件。
3. **起始区没有商人**：在墓地、草甸、岔路口三处扫过，一个商人也没找到。
   最近的商人在 **Goldshire**（Elwynn Forest 一带），而 3.3.5a 里
   **没有传送、没有寻路**，只能走过去。
4. **驱动目前没有导航能力**：朝固定方向盲走会撞进死角
   （实测在 (0.567, 0.437) 处东、北、东北、西北四个方向全部走不动，步长为 0），
   路径记忆只对**走过的路**有效 → 要到 Goldshire 这种没走过的目的地，
   需要"读小地图定方向"这一项能力（**尚未实现**）。
5. **"认出光标下的单位"这条机制已经打通**（v13）：把光标放到一匹马的模型上，
   客户端报出哈希 33001，与 Python 算出的
   `name_hash("Riding White Stallion")` 完全一致 ✓。
   之前扫描找不到名字，是因为网格太粗（110×100 像素）而单位的碰撞框只有
   ~20 像素 —— 机制没问题，是采样密度的问题 ✓。

## 还没验证的部分

- **打开商人窗口**（对 NPC 右键）、**卖出灰装**（卖东西页、确认框）、
  **修理**（修理页、Repair All）—— 这三步都还没走到，因为前面三道门
  （没钱、没有商人、到不了）先挡住了。
- 因此这条路径的结论是：**协议层已经就绪（金钱、背包、名字都能读），
  交互层一步都还没验**。

## 补做：小地图读数（导航的前置）

既然"到不了目的地"是硬门槛，就把小地图读出来：`scripts/client_minimap.py`。

- 小地图**以角色为中心**、**北在上** ✓（画面上确认）→ 标记相对圆心的方向就是世界方向 ✓。
- 标记的颜色实测有两种：任务标记的**饱和黄**（(255,223,0)）与
  蓝灰的**可接任务标记**（(72,81,114)）✓；区域名文字与缩放按钮是别的颜色 ✓，
  用半径 85 像素把它们排除 ✓。
- 朝向换算按客户端的位移公式 `u(θ)=(-sinθ,-cosθ)` 推出 `θ=atan2(-east,-south)` ✓。

**这里发现并修掉了一个符号错误**：第一版写成 `atan2(east,-south)`，
实机表现为**角色朝反方向走**——任务标记在小地图上从 17 像素远跑到 79 像素远 ✓，
轨迹把错误暴露得很清楚 ✓。现在有离线用例锁住"走的位移必须指向标记" ✓。

两张真实小地图存成夹具（`scripts/fixtures/minimap-*.png`），
离线用例覆盖：找到任务标记、排除区域名文字、朝向换算、
以及"按这个朝向走，位移必须指向标记" ✓。

**还没做完**：小地图上**哪个标记是哪个 NPC** 还没法分清（颜色分类只到"黄/蓝"，
玩家的箭头也还没可靠识别）→ 所以"走到任务 NPC/商人那里"这个动作**还不能算可靠**，
只能作为研究结论；下一步是读**大地图**（M 键，标记更大更好认）或先把箭头认准。

## 后续（用户提示"北郡修道院门外不远处就有杂货商人，小地图能看到"）之后

照这个提示做，路径通了：

1. **朝小地图上的标记走**（`scripts/lab_client_find_merchant.py`）：
   读小地图 → 取最近的标记 → 按 `atan2(-east,-south)` 换算朝向 → 走；
   **走不动就转向绕开**（实测角色一开始被墓地的墙挡住，加上绕行后标记距离
   从 44.6 缩到 17 像素 ✓，导航确实在收敛）。
2. **认人**（协议 v13 的光标读名 ✓）：到达后把光标按网格扫一遍四面的画面，
   读到的名字**直接显示在探针面板的文字里**（`cursor=Northshire Guard` ✓），
   每个名字还存一张截图 ✓。
3. 实机结果：角色走到了**北郡修道院**（位置 (0.4697, 0.4825)），
   tooltip 显示"Northshire Guard / Level 65 / Stormwind / PvP" ✓，
   探针读到的名字哈希 47902 = `name_hash("Northshire Guard")` ✓ **完全对上** ✓。

**下一步**（很短）：进修道院门 → 右键商人 → 商人窗口 → 卖出灰装，
用 `money` 与 `bag_items` 核对这一笔；拿到钱再试修理。
