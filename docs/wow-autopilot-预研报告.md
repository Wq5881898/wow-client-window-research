# WoW 自动化预研报告

更新：2026-09-23  
范围：World of Warcraft: Forever 个人账号自动化技术预研

## 1. 当前结论

项目已有静态 API、公开条款、历史资料、在线端点、合成仿真和工具 dry-run 证据，但没有目标客户端运行时证据。

静态资料足以形成若干积极但有条件的技术假设：玩家/队友位置、已选目标后的部分 Unit 状态、Assisted Combat、限制状态和若干数据路径值得真机验证；固定区域和固定目标可能降低感知复杂度。静态资料尚不能确定调用成功率、值可读性、完整闭环、动作效果或授权。

合成仿真的数值是真实机器输出，可以比较当前模型内部的策略和实现行为、支持敏感性分析并生成真机实验假设。它不提供真实游戏的性能、安全、恢复率、收益或授权证据。

用户已决定以直接个人自动化技术验证为主要方向，个人实验不等待 15C，并自行承担账号处罚风险。玩家主导产品 B 和 W1 不在技术主线。该决定不是 Blizzard 授权或法律意见。

## 3. 静态技术判断

### 3.1 位置与状态

`C_Map.GetPlayerMapPosition` 的归档文档明确列出 player/party member 用途、可空返回和参数限制标记。它为玩家位置提供了比纯猜测更强的架构依据，但目标 build 中是否可调用、多久返回一次有效值、误差和场景限制仍未知。

Unit 文档显示三类表面：明确 `SecretReturns`、条件 secret predicate、以及未标同类返回守卫。这支持按 API、unit token 和场景分别测量，而不是把 Unit 数据整体判为可用或不可用。

### 3.2 目标、战斗与采集

`TargetNearestEnemy` 是选择动作，不是敌人列表、位置、LOS 或种类接口。固定目标场景可能减少敌人集合感知要求，但目标有效性、额外敌人和动作结果仍可能需要 Unit 状态或画面观察。

Assisted Combat 可能提供下一技能或轮换候选，因而有机会减少职业逻辑维护；它不解决移动、目标发现、输入执行或所有战斗状态。

G6 的四枚举成员假设已失败。项目中还存在世界拾取对象、交互、Loot 和容器接口表面，所以当前只能否定旧枚举方案，不能否定采集观察本身。

### 3.3 数据与输入

SavedVariables、聊天和屏显代表不同的数据路径，静态依据不同。项目没有它们在目标 build 的到达率和延迟记录。

`t2_input_probe.py` 已具备默认 dry-run、明确解锁、前台窗口复核、逐次确认和 key-up 配对。它尚未发送真实输入；因此项目没有游戏输入效果数据。

## 4. 仿真与在线端点

v4 仿真修复了隐藏世界读取、校验路径不一致和完成时间近似等已知缺陷。结果文件中的比较可表述为“在当前代码、参数和随机种子组成的合成模型内”，并可用于选择下一项需要真机证伪的假设。

在线端点有效样本在秒到数十秒量级，且出现空响应、限流和协议失败。这些实际样本不支持把所测端点放入低延迟控制环；它们没有证明其他端点或异步用途无价值。

## 5. 条款与历史证据

2026-09-22 取得的官方 EULA 页面标注 2024-03-21 修订，文字涉及未获明确授权的 bot、自动控制、data mining、unauthorized connections、Beta 和监控。2009 来源的 addon policy 页面在抓取时仍公开。

本轮公开来源未发现 Forever 专项条款链接；客户端安装、授权和登录流程未检查。MDY、2016 Anti-Cheating Agreement 和竞品资料可形成风险和市场先验，但不能确定当前检测实现、处罚概率、个案授权或目标法域法律结论。

## 6. 市场材料

历史自动化和省时产品表明该类别长期存在。I01 记录了一位活跃玩家对跑图、带刷、死亡返回和采矿自动化的广泛诉求，但访谈未完成，没有频率、替代方案、支出、具体产品反应或试用承诺。

项目当前没有市场规模、价格、购买意愿或产品 B 可行性结论，也没有有效证据要求先做产品 B 再研究其他架构。

## 7. 研究状态

已经完成：静态 manifest、证据归档、合成模型 v4、在线端点历史样本、T2 dry-run 和一份未完成访谈。

尚未完成：目标 build 记录、真机 API/值/事件/效果观察、任何真实输入、固定目标闭环、当前反作弊实现调查、客户端附加条款检查，以及发布或商业化审查。

项目没有经验基线支持 `3/2`、`99%`、`p95 <= 500 ms`、`30/30`、固定时长或一次重测作为通用门槛。这些数字已从当前方法中撤销。具体实验可以记录样本数、错误、分位数和运行时长，但其解释需结合具体问题。
