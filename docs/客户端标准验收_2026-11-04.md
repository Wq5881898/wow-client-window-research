## 长归途变体（拉长可行路径距离）

危险区脚本新增 `--route`，另有 `scripts/lab_client_walk_out.py`：角色按固定朝向走，
走出多远由时间决定；`--from X Y` 先走到一个已知点再出发，让每次的距离可比。

实测的可行路径距离（同一次链里"再死一次"的两具尸体分别给出两个值）：

| 场景 | 尸体位置 | 到墓地的可行路径距离 |
| --- | --- | --- |
| 墓地旁死亡 | (0.50121, 0.43955) | **0.00610** |
| 往东走了一段 | (0.50898, 0.43755) | **0.01088** |
| 走出 0.015 再死 | (0.51148, 0.45211) | **0.02703**（第二具尸体 0.01798，更靠近墓地 ✓） |
| 走出 0.033 再死 | (0.51148, 0.45211) | **0.02315** |
| 走出 0.05 再死 | (0.52284, 0.47196) | **0.05096** |
| 走出 0.08 再死 | (0.57139, 0.47807) | **0.09347**（恢复超了时间预算） |

结论：

1. **可行路径距离确实随路程变化**（0.0061 → 0.0935，十几倍），不是常数 →
   这个度量可以拿来做"离墓地更近了吗"的判断 ✓（"再死一次"的对比就是靠它 ✓）。
2. **本区域的地面限制了距离**：往东走到 `(0.50869, 0.43760)` 就被地形挡住 →
   要走得更远得先规划路线，而不是一直朝一个方向走 ✓。
3. **长距离变体受恢复耗时限制**：幽灵要绕开石头走向远处的尸体，实测约
   原文估计0.0001单位/秒，但0.05除以该速率约500秒，并非40分钟；绕行、转向、观测和实际超时需按各run时间重算。状态机默认2400秒，当前危险区驱动显式传入240秒，不能混用两个预算。
   所以长距离变体适合作为**度量验证**，不适合作为常规任务。

### 长归途变体顺带查清的三件事

1. **`UnitDistance` 在 3.3.5a 不存在** → 探针的 `target_distance` 字段是垃圾值
   （恒为 65526/10）。所以"离目标多远"读不到，只能靠**施法失败的错误码**判断：
   5 = 目标不在正面、1 = 超距、6 = 视线被挡（`reason_code()` 的映射 ✓）。
2. **造死亡脚本改成按错误码自适应**：施法 → 读错误码 → 转身/前进 → 再施法，
   直到怪进入战斗；目标丢了就用 Tab 重新选 ✓（原先只施法一次，怪会走位 ✗）。
3. **幽灵的路径不一定走得了**：幽灵会飞，尸体靠着墙时它能到，活着的主角走不了 →
   撤离卡住三次后改为**直接朝墓地走** ✓（直线）✓。

## 这次踩到并修掉的坑

1. **菜单开着时不能再按 ESC**。原来"找不到 Logout 就按 ESC"的循环，在菜单已经
   打开、但按钮识别失败时会把菜单**关掉**，于是永远找不到。
   现在改成 `client_read_fresh.open_menu_logout()`：只在菜单**不在**屏幕上时按
   ESC，并且每轮先把客户端置前（键是真实输入，只发给有焦点的窗口）。
2. **客户端被关掉时角色留在服务端是幽灵**。上一环失败后角色死在墓地，
   客户端被重启脚本杀掉 → 服务端记的是幽灵 → 下一次登录进世界就是幽灵。
   现在 `lab_client_enter_character.py` 认得出这种情况：读到 `dead` 就
   `release_spirit()` 关掉死亡窗口，角色回到墓地，流程可以继续。
3. **角色升级后，用血量证明"是同一个角色"的硬编码区间会误判**。
   Probehuman 已从 52 血升到 67 血（等级 2），期望区间放宽到 40–200。
4. **战斗闭环原来不走路**：角色被墓地的狼撵到别处后，Tab 选不到怪。
   现在选不到目标时先走到怪出现过的位置 `(0.50390, 0.44147)` 再选。
5. **会话必须是 console 型**（见手册"客户端起不来：先看会话类型"）：
   RDP 会话里 WoW 3.3.5a 拒绝启动，客户端进程能起但没有游戏窗口。
6. **战斗中按 ESC 不开菜单**：WoW 在战斗时不给开游戏菜单 → 重登脚本一直找不到
   Logout 按钮。现在先 `wait_out_of_combat()` 等脱战再开菜单 ✓。
7. **客户端被关掉后角色留在服务端是幽灵**，而且此时**已经没有死亡窗口可释放**
   （灵魂早就放了）→ 进世界脚本现在改为直接调用恢复流程：幽灵走向尸体、复活、撤离 ✓。
8. **"再死一次"没发生时角色会停在危险区里** → 恢复脚本现在让它沿原路走回墓地再收尾 ✓。
