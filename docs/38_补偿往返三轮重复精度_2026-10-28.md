# 补偿往返三轮重复精度

沿用前进 0.15 秒、后退 0.233333 秒，新增 trial1–3 独立场景。每轮依次采 baseline、forward、back、final，轮末 reload 落盘；核验成功后才开始下一轮。三轮交互任务均退出码 0。

## 结果

单位为归一化地图坐标，非码数。

| 轮次 | 返回 Δy | 相比等时长控制组绝对残差减少 |
| --- | ---: | ---: |
| 1 | +1.6987323761e-06 | 98.9516% |
| 2 | -4.1723251348e-07 | 99.7425% |
| 3 | +2.5331974030e-06 | 98.4366% |

- 平均绝对 y 残差：1.5497207642e-06；最大：2.5331974030e-06。
- 第一轮基线至第三轮最终样本约 410.017 秒，累计 Δy=+3.8146972656e-06。
- 各轮 Δx 和朝向残差均为 0。
- 每轮 back 与 final 一致；下一轮 baseline 与上一轮 final 的 x、y、facing 完全一致。
- 十二个快照均通过 Probehuman、生命 52、非战斗、无目标、北郡、speed=0 校验。

补偿在三个重复样本中均明显减少误差，但残差方向和大小变化，不代表精确返回。这里是轮间 reload 的离散实验，不是全程连续遥测，也未实现实时位置反馈纠偏。初始截图中角色呈坐姿，第一轮前进位移略小于第二轮；没有独立对照，不能断言坐姿是差异原因。后续如需比较更细精度，应统一起始姿态并记录实际输入持续时间。
