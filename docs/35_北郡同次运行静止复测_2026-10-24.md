# 北郡同次运行静止复测

## 目的与过程

补充上一轮跨重启分段数据：在同一次客户端运行中取得三次静止快照，样本间不执行 reload，第三次截图后才统一 reload 落盘。

预检发现 Wow.exe 仍在 Session 1，但处于角色选择界面；已选中 Probehuman。进入世界后截图确认北郡、角色和正常游戏界面，再运行交互任务 `WoWLabNewbieContinuous`。

执行脚本：`scripts/lab_newbie_continuous.py`。本轮不发送移动输入。聊天使用 Enter、WM_CHAR、Enter，入口截图已确认聊天和菜单均关闭，因此无需无条件 Escape。阶段间等待 10 秒，加上探针、输入和截图耗时，实测快照间隔约 31.8 秒。

任务启动后轮询 Running 状态直至完成，退出码 0；没有固定等待后重叠启动下一任务。

## 结果

| 快照 | 相对首个快照时间（秒） | Δx | Δy | Δfacing |
| --- | ---: | ---: | ---: | ---: |
| newbie_continuous_1 | 0 | 0 | 0 | 0 |
| newbie_continuous_2 | 31.784 | 0 | 0 | 0 |
| newbie_continuous_3 | 63.517 | 0 | 0 | 0 |

三个样本全部验证：Probehuman、生命值 52、非战斗、无目标、Northshire Valley、speed=0、地图位置有效。样本时间严格递增，位置和朝向逐值一致。

这是约 63.5 秒跨度内的三次快照，不是逐帧遥测，不能排除快照间未观测到的短暂变化，也不代表移动闭环或长时间稳定性已经验证。
