# 90° 转向重试策略与错误码驱动施法（2026-11-13 傍晚）

状态：策略实机验证通过（1 次 90° 转向后命中击杀）；仍是 `target_gone_unconfirmed`，不算严格击杀。

## 起因

用户建议：**当出现"目标不在面前"提示时，快速转 90° 再试，报错再试，最多 3 次即可面向目标**。本轮把它做成可单测的决策模块并接入实机。

## 做法

新增 `scripts/client_cast_step.py`（纯逻辑，不碰游戏）与 `scripts/test_client_cast_step.py`（8 项单测）：把客户端的施法失败原因码变成显式决策。

| 原因码 | 客户端含义 | 决策 |
|---|---|---|
| 1 | 目标超出射程 | `approach`（靠近，而不是转向） |
| 2 | 法力不足 | `rest` |
| 3 | 技能未就绪 | `wait` |
| 4 | 无目标/无效目标/已死 | `verify` |
| **5** | **目标需要在你面前** | **`turn` 90°（0.55 秒）→ 再施法；最多 3 次；仍不行则退化为 40° 细扫（最多 8 次）** |
| 6 | 无视线 | `turn` 90°（计入细扫） |

另外两条保护分支不变：血量 < 110 且目标血量 > 47 → 撤退；法力 < 18 → 撤退。错误判定用**增量**（`cast_failed`/`ui_errors` 计数变化）而不是常驻的 `last_error_reason`，否则一次报错后会一直重复转向。

## 实机结果（批次 268 秒）

| 项 | 值 |
|---|---|
| 战斗 | 2 场，**+47 经验**，**630 经验/小时**（含 194 秒恢复），**0 死亡** |
| 角色 | 9级 271→318 经验、172/172 血、378 蓝、存活脱战 |
| 时间结构 | 战斗 17.0 秒、选怪 36.5 秒、恢复 194.4 秒、移动 12.3 秒 |

**第二场战斗是策略的直接证据**：目标 120 血狼在选中时已掉到 75 血，首个施法报 reason=5 → **1 次 90° 转向（0.55 秒）** → 连续施法命中 → 目标血量 75→0、施法成功计数 1→3、角色掉到 100 血（狼有还手）、`result=target_gone_unconfirmed`、蓝 378→344。

**第一场战斗暴露策略的边界**：连续 2 次 90° 转向后，目标在施法间走出射程（`spell_range` 0）→ 决策切到 `approach` → 圆周逼近失败 → `approach failed; retreat` → 恢复 194 秒。也就是说：**90° 转向能解决"朝向"，但解决不了"距离"，而且转向期间目标可能跑出射程**。

## 结论

1. 用户建议的"报错→转 90°→再试"**成立并已实机验证**：reason=5 用 90° 步进比原来的 40° 细扫更快（1 次就中），单场 17 秒内结束。
2. 失败模式清晰：reason=5 与 reason=1 会交替出现；转向本身不移动角色，靠时间换角度可能让目标脱战/脱手。需要在 `approach` 分支有更好的方向来源（见下）。
3. 本轮 630 经验/小时，**仍低于 626.6 基线附近但只有 2 只样本**，且 194 秒恢复占了 72% 时间——不构成"提速通过"，只说明**战斗环节已经不是瓶颈**。

## 仍未解决（需要方向/距离读数）

- `spell_range=0` 的目标只能靠圆周逼近，40 码外无效（今日实测）。
- 客户端不提供 `UnitDistance`、不提供单位坐标；`/startattack` 不会把角色带过去（err 0→26 反复报射程外）。
- 聊天命令探测（`/print`）被输入层吃掉：`/say apitest` 正常回显，`/print(1)`、`/print UnitDistance` 均无回显（聊天框为空），**API 可用性仍未知**。

## 下一步

1. **方向读数**（阻塞项）：小地图敌对箭头可离线取像验证（10×8 白三角箭头），但圆心拟合与阈值需标定；或扩展探针加只读字段（目标等级、逐次施法错误原因、相机/屏幕方位）。
2. `approach` 分支改为"转向时优先保持目标在射程内"（比如先转向到 reason 不再是 1 再走），避免边转边脱战。
3. 批次仍按 5–10 只 / ≤15 分钟验收，0 死亡才算样本。

## 边界

- 2 只狼均为 `target_gone_unconfirmed`，**没有同 GUID 死亡帧**。
- 90° 步进的角度依赖实测转向速率 2.9 rad/s（`scripts/client_motion.py` 的 TURN_RATE）；换窗口/DPI 需重新标定 0.55 秒。
- owner 改动在 `.cache/desktop-check/`（不入库）；可复用决策模块在 `scripts/client_cast_step.py`（入库）。
