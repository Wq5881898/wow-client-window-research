# 平坦区域短步位置对照（2026-10-21）

## 结论

在本地 AzerothCore / 3.3.5a，Goldshire 道路区域，分别持续按 W、S 各 0.5 秒，读取到方向相反的非零地图位置变化。随后无移动复测位置完全一致，所有采样后 GetUnitSpeed 为 0、生命 142、非战斗、无目标。

同样时长的前进与后退没有回到原点。单次样本只能说明输入时长与位移不对称，不能区分后退速度、输入延迟、地形及其他因素的贡献。

## 仪器与流程

1. `.tele goldshire` 设置实验区域，截图核对地形与小地图 Goldshire 标签。
2. 清除目标，`/wp once flat_setup` 创建只读快照。
3. 外部 `/run SetMapToCurrentZone()` 明确地图上下文。
4. 外部 `/run` 读取 GetPlayerMapPosition、GetPlayerFacing、GetUnitSpeed，将 motion_* 标量附加到该 run.meta。
5. `/reload` 落盘。前进、后退及静止采样分别在独立交互任务运行，并逐次核对截图。

motion_* 是外部实验仪器追加的观测，时间晚于同步快照；并非插件原本已具备的原子位置记录。本轮没有修改只读插件源码。

首次 setup 因聊天框/输入通道状态没有成功传送或采集；修正后已通过 Goldshire 截图和新增 motion_* 落盘字段确认成功。不以任务进程仍存活或输入 API 返回成功代替场景证据。
