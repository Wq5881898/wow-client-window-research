# 15C 条款澄清状态

更新：2026-09-23  
说明：本文件原为助手拟定的官方询问和专业审查问题包。该问题包尚未发送，也没有取得答复；它不再作为个人技术实验的阶段 gate。

## 1. 已有材料

- 2026-09-22 抓取的 Blizzard EULA 页面标注 `LAST REVISED March 21, 2024`。
- EULA 归档文字涉及未获明确授权的 bot、自动控制、data mining、unauthorized connections、Beta 和监控。
- UI Add-On Development Policy 官方论坛页在抓取时仍公开，正文来源于 2009。
- 2026-09-17 Forever Beta 公告和本轮审阅的 Blizzard Legal 索引中未发现 Forever 专项条款链接。
- 客户端安装、Beta 授权、首次启动和首次登录流程尚未检查。
- 没有 Blizzard 针对本项目的书面答复。
- 没有目标法域专业人士针对本项目的书面意见。

## 2. 尚未回答的事实问题

- 诊断 addon 调用文档化 API 并在游戏内显示结果的具体适用范围。
- SavedVariables 在正常 reload/logout 后由外部程序读取的适用范围。
- addon 屏显后由外部程序观察像素的适用范围。
- 纯窗口截图用于离线分析的适用范围。
- 用户逐次触发的单个外部键盘输入与连续自动输入在合同分析上的差异。
- 玩家主导 addon、付费内容和站外更新服务与 2009 policy 的关系。
- Forever/Beta 是否有未被公开页面检索覆盖的附加条款。
- 目标法域下 EULA、版权、反规避、隐私、消费者和商业合同问题。

这些是未决问题，不表示某项行为被允许或禁止。

## 3. 用户决定

用户已决定个人账号技术实验不等待上述问题取得书面答案，并自行承担账号处罚风险。该决定不改变现有条款文字，也不构成 Blizzard 授权或法律结论。

发布、分发、招募其他账号测试和商业化尚未发生，相关授权与专业审查也尚未取得。

## 4. 归档事实

旧版助手问题包曾拟定 8 项 Blizzard 问题、10 项专业审查问题以及“满足 15C”的标准，但从未发送。其历史内容可从会话日志和审查前快照恢复；不再作为当前项目规则。
