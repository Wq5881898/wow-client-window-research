## 自动释放：试过什么、为什么都不通

| 路径 | 结果 | 原因 |
|---|---|---|
| 游戏内 GM 命令 `.revive` / `.resurrect` / `.heal` | 无效 | **幽灵态下聊天输入框不接受打字**：诊断脚本逐步截图证明，按 Enter 打开的输入框有焦点、打字能落进去；打点号命令时开头的"."落到世界里变成了法术热键（探针 UI 错误计数从 25 涨到 35、错误原因 4=无目标） |
| 仓库自带 `scripts/lab_client_gm_recover.py` | 无效 | 同一条聊天通路；顺带修了它的两个真 bug：GM 命令必须带**点号**而不是斜杠；`scripts/lab_client_login.py` 的协议白名单漏了 **15**，导致它在协议 15 的客户端上永远报"面板缺失" |
| 服务端控制台 | 不可达 | 世界服是 **Windows 服务**（父进程 services.exe），没有控制台窗口，`scripts/lab_console_input.py` 找不到窗口 |
| 服务端 SOAP `scripts/lab_soap.py` | HTTP 401 | 账号认证不通过（SRP 口令无法服务端校验明文） |
| 幽灵走进墓地 | 无效 | 探针位置恢复可读后，用位置反馈做了螺旋扫荡与 13×13 网格扫荡（约 4 小时、上千步）：幽灵确实在移动，但**这版客户端不会因走进墓地自动释放** |
| 登出重进（3 次） | 无效 | 死亡对话框只在死亡瞬间出现；重登后幽灵直接出现在墓地仍是幽灵 |
| 换同账号的活人角色（Syra）再发命令 | 未达成 | 角色选择页用打字选角色不生效，方向键也未改变选择；且登出点击受窗口位置变化影响 |

**结论**：这版客户端释放幽灵只认死亡瞬间的 "Release Spirit" 对话框（或其对应的 CMSG_RELEASE_GHOST 报文），而该对话框已经在我误点关闭后不再出现；服务端通道在本机不可用。因此**这一步需要人点一下**。
