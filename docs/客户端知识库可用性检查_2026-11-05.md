## 实际查询样本

执行入口：在项目根目录运行 `python -B -X utf8 scripts/client_kb_check.py --find "关键词"`。

| 查询 | 实际命中 | 结果 |
| --- | --- | --- |
| 商人 | NPC-01、TXN-01 | 区分发现对象与交易核验 |
| ACC-01 | ACC-01 | 直达目标消失/击杀问题 |
| 失联 | CTL-01 | 定位异常出口、取消和恢复 |
| 3.3.5 | VER-01 | 定位版本兼容边界 |
| acc-01\|npc-01 | ACC-01、NPC-01 | 英文大小写忽略，多关键词按或匹配 |
| NO_MATCH_20261105 | 无命中 | 给出缩短关键词/全文搜索提示，退出码2 |

这只是关键词索引，不对任意完整自然语言问题作语义检索。主题页和来源摘要可离线读取，外部源码全文未整包镜像；离线情况下仍可查本地摘要，不能离线打开未缓存外链原文。
