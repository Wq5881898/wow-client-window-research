## 2. README 摘录

### Hekili `README.md`（raw，2026-09-27）

开头明确：Retail 项目在 Midnight 预补丁 12.0（2026-01-20）结束。理由是 Blizzard API 新方向使其无法继续满足设计目标和质量标准。

旧 README：优先级助手；用当前角色状态（冷却、资源、光环、附近敌人）按 SimulationCraft APL 向前模拟；显示推荐技能，由玩家按键。

`Hekili.lua` 含 `Hekili.IsMidnight = buildNum >= 120000`。`Targets.lua` 目标集合来自固定 unit token（`target`/`focus`/`bossN`/`arenaN`）加 nameplate GUID 映射，另有宠物技能探距注释。不是世界敌人枚举器。

### GSE `README.md`（raw master，2026-09-27）

自述：不能打破暴雪规则；每次点击发送一块命令栈；每次点击只能尝试一个 GCD 技能；由 Semlar GnomeSequencer 演化而来。

### WeakAuras README（raw main，2026-09-27）

显示框架：光环、生命、能量、冷却、战斗事件等触发器；自定义副作用包括聊天提示和音效。玩家仍看屏操作。另有进程外 Companion 用于从 Wago 更新配置，不是战斗控制环。
