# Category:API functions/restricted

From Warcraft Wiki

<[Category:API functions](https://warcraft.wiki.gg/wiki/Category:API_functions "Category:API functions")

[Jump to navigation](https://warcraft.wiki.gg/wiki/Category:API_functions/restricted#mw-head)[Jump to search](https://warcraft.wiki.gg/wiki/Category:API_functions/restricted#searchInput)

👉_See also: [Object security](https://warcraft.wiki.gg/wiki/Object\_security "Object security")_
Addons and macro scripts are insecure code and are bound by different measures of restrictions when calling API functions. If [taint](https://warcraft.wiki.gg/wiki/Secure_Execution_and_Tainting "Secure Execution and Tainting") spreads to the rest of the UI this will render Blizzard code insecure too.

## protected

APIs which cannot be called by [insecure code](https://warcraft.wiki.gg/wiki/Secure_code "Secure code"). Fires [ADDON_ACTION_FORBIDDEN](https://warcraft.wiki.gg/wiki/Event:ADDON_ACTION_FORBIDDEN "Event:ADDON ACTION FORBIDDEN").

/run JumpOrAscendStart()

![Image 5: API restricted 01.png](https://warcraft.wiki.gg/images/API_restricted_01.png?3eae5e)

_`*** ForceTaint\_Strong ***` means it was called from a /run script, otherwise this would normally be the addon name._

## hwevent

APIs which require a hardware event (like the user clicking a button). Fires [ADDON_ACTION_BLOCKED](https://warcraft.wiki.gg/wiki/Event:ADDON_ACTION_BLOCKED "Event:ADDON ACTION BLOCKED").

/run C_Timer.After(0, function() SetCurrentTitle(47) end) -- does not work

## nocombat

APIs which cannot be called in [combat](https://warcraft.wiki.gg/wiki/API_UnitAffectingCombat "API UnitAffectingCombat"). Fires [ADDON_ACTION_BLOCKED](https://warcraft.wiki.gg/wiki/Event:ADDON_ACTION_BLOCKED "Event:ADDON ACTION BLOCKED").

/run CreateMacro("test", 136243) -- does not work in combat

## secureframe

Widget APIs which cannot be called on [secure frames](https://warcraft.wiki.gg/wiki/SecureTemplates "SecureTemplates") in combat. Fires [ADDON_ACTION_BLOCKED](https://warcraft.wiki.gg/wiki/Event:ADDON_ACTION_BLOCKED "Event:ADDON ACTION BLOCKED").

/run ActionButton1:Hide() -- does not work in combat

![Image 6: API restricted 02.png](https://warcraft.wiki.gg/images/API_restricted_02.png?e448c9)

## restrictedframe

Widget APIs which cannot be called on [restricted frames](https://us.forums.blizzard.com/en/wow/t/ui-changes-in-rise-of-azshara/202487) such as nameplates. Throws a Lua error.

/dump NamePlate1:GetBottom() -- Error: [string "return NamePlate1:GetBottom()"]:1: Action[FrameMeasurement] failed because[Can't measure restricted regions]: attempted from: NamePlate1:GetBottom().

## noscript

APIs which cannot be called _directly_ from a [/run](https://warcraft.wiki.gg/wiki/MACRO_script "MACRO script") script or WeakAura. Fires [ADDON_ACTION_BLOCKED](https://warcraft.wiki.gg/wiki/Event:ADDON_ACTION_BLOCKED "Event:ADDON ACTION BLOCKED") or silently fails, depending on the API.

/run C_AuctionHouse.SearchForFavorites({}) -- does not work and also bricks the AH in the process

Putting it inside a function in an addon and then calling it manually works.

function Example() -- /run Example()
C_AuctionHouse.SearchForFavorites({})
end

-- or as a button
local btn = CreateFrame("Button", nil, UIParent, "UIPanelButtonTemplate")
btn:SetPoint("CENTER")
btn:SetSize(120, 40)
btn:SetText("Example")
btn:SetScript("OnClick", function(self, button)
C_AuctionHouse.SearchForFavorites({})
end)
